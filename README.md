# 👷 Construction Site Safety & Hard Hat Detector

An AI-powered computer vision web application built with **Streamlit** and **Roboflow Workflows** to detect PPE (hard hat) compliance on construction and industrial sites in real time.

## 🚀 Key Features
- 📷 **Live Camera & File Upload:** Snap live photos directly inside the browser or upload existing image files.
- 🎨 **Dynamic Color-Coded Bounding Boxes:** Visualizes compliance with custom color badges (Green for hard hats, Red for safety violations).
- 🎚️ **Interactive Confidence Filtering:** Real-time sidebar slider to adjust detection sensitivity.
- 📊 **Safety Compliance Analytics:** Instant count metrics, violation alerts, and detailed detection logs.
- 📥 **Export Capability:** Download labeled audit images directly to your device.

## 🛠️ Tech Stack
- **Frontend & Deployment:** Streamlit Community Cloud
- **AI Engine:** Roboflow Inference SDK & Workflows
- **Image Processing:** OpenCV, NumPy, Pillow, Pandas
